# 第二阶段创新设计：有限记忆排斥跳变与后验可靠度译码

## 为什么第一阶段仍不足

第一阶段完成了公平性纠错，但主要贡献是“解释现象”，缺少新的发射或接收
算法。若直接投稿，审稿人容易认为工作只是更严格的仿真基线。第二阶段必须
形成“方法、理论、实验”闭环，并明确不与已有 no-hit-zone / wide-gap 跳频
序列工作争夺不成立的首创性。

## 方法定位

提出 **MCSH-BRW**：

- **MCSH（memory-constrained sparse hopping）**：每个 OFDM 符号选择
  `S` 个激活子载波时，优先排除最近 `L_h` 个符号使用过的物理子载波；当
  可用子载波不足时，选择近期使用次数最少的子载波。
- **BRW（Bayesian reliability weighting）**：把接收样本建模为 clean/jammed
  两方差高斯混合，根据 QPSK 边缘似然计算每个激活子载波被干扰的后验概率，
  连续缩放软度量，而不是直接执行二值擦除。

该方法不依赖强化学习训练。跳变图案可由共享密钥和确定性伪随机数生成；
BRW 需要噪声方差和干扰方差的估计值，论文必须报告估计失配敏感性。

## 可证明性质

令物理栅格大小为 `N`，每符号激活集合为 `A_m`，`|A_m|=S`。若

```text
(L_h + 1) S <= N,
```

则 MCSH 可以保证

```text
A_m ∩ (A_{m-1} ∪ ... ∪ A_{m-L_h}) = ∅.
```

因此，对任意延迟 `d <= L_h` 的单拍跟随干扰
`J_m = A_{m-d}`，除初始获取阶段外碰撞率为零。对攻击最近若干跳集合并集的
多拍跟随干扰，只要其记忆不超过 `L_h`，也具有相同的零碰撞性质。独立随机
跳变对单拍跟随干扰的期望碰撞率仍为 `S/N`。

该性质与标量 FHS 的 no-hit-zone 思想相关，但本文研究对象是每拍同时激活
多个频点的集合值稀疏 OFDM，并联合研究编码软度量、衰落和同步误差。

## BRW 度量

对均衡后的激活子载波样本 `y`，定义两个假设：

```text
H0: y = x + n,       n ~ CN(0, v0)
H1: y = x + n + j,   n+j ~ CN(0, v1), v1 > v0
```

对未知 QPSK 符号 `x` 做边缘化，使用先验碰撞概率 `pi` 得到
`q = P(H1 | y)`。随后用

```text
w ∝ 1 / ((1-q) v0 + q v1)
```

缩放 QPSK 软度量。`q` 接近 1 时软信息趋于中性；`q` 接近 0 时保留原始
软信息。实现中该权重直接进入加权 Viterbi 分支度量。该方法与 hard erasure、
无加权和 oracle erasure 分开比较，并在随机跳变和 MCSH 上分别运行，以拆分
跳变图案与接收机的贡献。

## 必做实验

1. **核心 BER**：Sweep、延迟 1/2 拍跟随、多拍跟随；对比随机跳变、MCSH、
   MCSH+hard erasure、MCSH+BRW、oracle。
2. **记忆深度消融**：`L_h=0...6`，实际干扰延迟 `d=1...6`。
3. **JSR 鲁棒性**：`-5...15 dB`。
4. **衰落与 CSI**：AWGN、Ped-A、Veh-A；完美 CSI 与估计误差。
5. **跳变同步误差**：不同图案失步概率。
6. **BRW 参数失配**：干扰方差估计误差。
7. **复杂度与运行时间**：图案生成、后验权重和 Viterbi 解码的量级与实测。
8. **无收益/失败场景**：Blind PBJ 和超出设计记忆的跟随延迟，避免只报告
   有利场景。

## 论文创新点边界

可以主张：

1. 面向集合值稀疏子载波跳变的有限记忆排斥构造及延迟跟随碰撞保证。
2. 后验可靠度加权与 MCSH 的联合接收设计。
3. 在共同物理栅格下，对延迟失配、衰落、CSI、同步和参数失配的系统评估。

不应主张：

- 首次提出 no-hit-zone 或低碰撞跳频。
- 密码学安全性。
- 对未知零延迟反应式干扰的完全规避。
- 在所有干扰场景中都优于随机跳变。
